## 🎯 About Me

- 🔐 Building AI systems at the intersection of **machine learning, security, and decentralized infrastructure**
- 🧠 Currently researching **decentralized AI memory architecture** — combining blockchain-based access permissions with encrypted memory storage, using **TEEs + on-chain attestation** to minimize (not just claim to eliminate) inference-time trust
- 🎙️ Designing a **self-hosted AI interview platform** with an agentic pipeline (LangGraph state machine, real-time STT/TTS, AI avatars) integrated with a custom ATS
- 🛡️ Practicing **offensive security** hands-on through HackTheBox — enumeration, exploitation, and privilege escalation
- 📍 Based in Chennai, India
- 🌱 Always learning — from mathematics to ML/DL/LLM concepts, built from scratch
